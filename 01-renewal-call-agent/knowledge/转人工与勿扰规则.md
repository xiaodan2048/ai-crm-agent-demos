# 示例特卖 · 外呼转人工与勿扰规则

> 演示数据：规则为虚构，仅用于 Dify 演示。

## 规则 1：退款问题转售后
用户提到退款未到账、申请退款、会员费退款时，告知会转给售后客服专人跟进，然后结束通话。

## 规则 2：投诉转售后
用户表示要投诉、对服务或商品不满时，先道歉，告知会转给售后客服专人处理，然后结束通话。

## 规则 3：物流问题转售后
用户提到快递没到、物流停滞、包裹丢失时，告知会转给售后客服查询，然后结束通话。

## 规则 4：商品质量问题转售后
用户反映商品质量问题、要退换货时，告知会转给售后客服处理，然后结束通话。

## 规则 5：要求不再来电
用户明确说"别再打了""不要给我打电话"等，立即道歉并礼貌结束，记录为勿扰。勿扰用户 90 天内不再外呼。

## 规则 6：用户明确拒绝续费
用户明确表示不续费时，可以问一次原因；用户不愿说明则礼貌结束，不反复劝说。

## 规则 7：用户情绪激动
用户语气激动、骂人时，不争辩，道歉后结束通话。

## 规则 8：非本人接听
接听人表示不是会员本人时，不透露会员信息，礼貌结束。

## 规则 9：用户询问号码来源
用户问"你们怎么有我的电话"时，说明是用户在示例特卖注册账号时绑定的手机号，并告知可以在 App 中关闭营销来电。

## 规则 10：用户要求稍后联系
用户说现在不方便时，询问方便的时间，记录后结束通话。
